# ADR-0006 · 版权合规与内容撤下

> **Status**：Accepted（2026-11-15 聚合定稿）
> **覆盖决策**：D-018、D-019、D-023、D-024、D-025、D-028
> **相关**：`NOTICE.md`、`数据来源.md` §四、`ADR-0007`

## Context

本库同时在三种许可下运作：代码层 AGPL-3.0（StarRailRes 强制）、BWiki 内容 CC BY-NC-SA 4.0、以及 HoYoverse 素材的官方同人指引。三方义务不同，混标即违规。
2026-10-02 的 W-4.6-19 事件是分水岭：米游社官方 Wiki 词条声明「禁止转载」，库内照搬的任务描述与逐句对话必须撤下；BWiki 内容则可保留但须履行 BY / NC / SA 三义务。
期间还出现两个判断错误：一是「全库 `CC BY-NC-SA` 0 命中 → 义务未履行」（实际是全角空格 U+3000 导致 ASCII grep 漏检）；二是「工作区改了就等于 GitHub 撤下」（实际版本库跟踪状态未变）。

## Decision

1. **许可分层标注**：代码层 = AGPL-3.0；内容层若来自 BWiki = CC BY-NC-SA 4.0（BY 署名 + NC 非商业 + SA 相同方式共享），若为 HoYoverse 数据/文本 = 受官方同人指引管辖；**两层分别标注、不得混用**；LICENSE 标准正文不得改动，限缩声明写入 `README` / `NOTICE` / `数据来源.md`（D-018）。
2. **只取事实数据为最低风险路径**：数值、星级、命途、名称、结构等事实性字段可用；表达性正文（成段描述、逐句对话）不搬。
3. **撤下范围与方式**（D-023 方案甲）：米游社来源的 91×5 个文件**原地清零表达** + 保留事实与结构（保 31 个引用目标不断链）；BWiki 裸抓取 74×5 清洗样板 + 补独立 CC 署名；**不做整文件 `git rm`**。
4. **「撤下」必须落到版本库**：工作区删除 ≠ 已撤下。需要 `git rm -r --cached` + `.gitignore` 条目 + 提交（D-024 → D-025，836 个跟踪文件移出版本库，本地文件保留）。
5. **非官方译文的处置口径**：`en_us` / `zh_tw` 的 `quest/剧情文本/` 中 LLM 译文与未翻译中文残留一律替换为 `> 机器翻译内容已撤下…`（99 个文件，占位符文件不动），`ja_jp` / `ko_kr` 本无残留不改（D-028）。
6. **宽匹配复核**：涉及许可 / 禁词 / 来源的 grep，必须同时跑 ASCII 与全角匹配，并说明「命中是抓取样板还是规范署名」——二者法律含义不同（D-019）。

## Consequences

- **正面**：三种许可各有落点，可在外审时逐项举证；撤下动作可被 `git ls-files` 复算。
- **负面**：剧情文本永久失去正文价值，站点对应链接只能走降级（见 ADR-0015 的死链降级）。
- **风险**：任何「换个措辞重写官方 Wiki 段落」的做法都属规避，禁止；取不到官方本地化时唯一正确动作是写「待补充」并登记。
